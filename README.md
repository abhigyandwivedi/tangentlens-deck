# Analytica Business Engine — Powered by Tangent Lens

An executive product-introduction deck: 15 slides taking an operations audience from
fragmented telemetry to governed, auditable decisions.

**View it:** https://abhigyandwivedi.github.io/tangentlens-deck/

## Navigating

Desktop: arrow keys (`←` / `→`) or `PageUp` / `PageDown`, or the arrow buttons at the
bottom.

Mobile and tablet: **swipe left or right** to change slide, or use the arrow buttons. Each
slide scrolls on its own, so long slides read top-to-bottom. Tap any screenshot to open it
full screen; pinch to zoom, tap to close. A thin progress bar at the top shows where you
are.

Deep links work too — append `#7` to open slide 7 directly.

The deck is a single self-contained HTML file — no build step, no dependencies, no network
calls.

## About the evidence

Screenshots are from a live Tangent Lens workspace, captured at Mac laptop resolution and
embedded as data URIs. The account owner's email address in the metrics view is blurred.

Claims in the deck are classified three ways:

- **Documented** — stated in the official Tangent Lens documentation.
- **Inferred** — a reasonable reading of documented behaviour, not itself documented.
- **Proposed SLA** — a deployment target, not a contractual commitment.

Example domains are deployment patterns built on documented primitives, not published
product verticals.
